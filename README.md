# Mubarek Bora — Portfolio

Personal portfolio site, listing projects and a resume link. Plain HTML/CSS, no build step.

**Live:** https://mubarek-boraportifolio.netlify.app

## Structure

- `html/` — the site itself (`index.html`, `styles.css`); this is the Netlify publish directory (see `netlify.toml`)
- `Documentation/`, `psd/` — leftover assets from the original ThemeForest template this repo started from; unused, kept for reference

## Updating

Edit `html/index.html` (projects, resume link) or `html/styles.css`, then commit and push. Once this repo is connected to the Netlify site (Site settings → Build & deploy → Connect to repository), every push to `main` deploys automatically.
